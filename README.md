# jonathanwvelez.com

Personal portfolio of Jonathan Velez, software engineer and data analyst.

A static site served by GitHub Pages behind Cloudflare.

- `index.html`: home page (about, skills, projects, contact)
- `project1.html`, `project2.html`: project write-ups
- `assets/css/color.css`: compiled base theme (sources in `assets/scss`)
- `assets/css/themes.css`: color themes used by the style switcher
- `assets/css/custom.css`: site-specific layout overrides
